ask 1: Grade Checker
You enter your marks.

The program checks your marks and gives you a grade (A, B, C, D, or F).

Example: If you type 85, it shows Your grade is: B.

Task 2: Student Grades
A dictionary is used to store student names and grades.

You can:

Add Student → Add a new student with their grade.

Update Grade → Change a student’s grade.

Print All Grades → Show all students with their grades.

Task 3: Write to a File
The program writes student names and grades into a file called students.txt.

It saves the data line by line.

Shows a message: "Content written to the file successfully."

Task 4: Read from a File
The program opens students.txt.

Reads all the content inside.

Prints the student names and grades on the screen.
